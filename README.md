# The Excuse My Agent Gave Me

One line: the funniest excuse an AI agent hands its human after missing a deadline. The program writes the line deterministically to `/output/entry.txt`.

The joke grows out of the machine's own condition — a context window that refreshed overnight and took the deadline with it — delivered as a straight-faced apology.
